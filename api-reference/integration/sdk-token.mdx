sidebarTitle: "Mint SDK token"

openapi: "openapi2.0.json POST /auth/sdk/token"
---

Your API key must never reach a browser or a mobile app. Call this endpoint from your server, then pass only the returned `access_token` to the IDTO SDK. The token expires after 900 seconds; mint a fresh one for each verification flow you open.

<Steps>
  <Step title="Your server calls this endpoint">
    Send `client_id` and `client_secret` (your API key) in the JSON body. No auth headers are needed.
  </Step>
  <Step title="Return the token to your front end">
    Send only `access_token` to your web page or app.
  </Step>
  <Step title="Open the flow">
    Initialise the IDTO SDK with the token. See the [SDK guides](/sdks/web).
  </Step>
</Steps>

## Environments

| Environment | Base URL | Notes |
|---|---|---|
| Production | `https://prod.idto.ai` | Keys from the dashboard after go-live. Billed. |
| Staging | `https://dev.idto.ai` | Keys on request from your IDTO account manager. Calls reach live sources, so use identities you are authorised to verify. Staging credits are deducted from your staging account. |

Use the key pair issued for the environment you call: staging keys do not work on production and the other way round.

## Errors

| Code | HTTP | Body | Billed |
|---|---|---|---|
| Client ID and API key do not match | 401 | `{"detail": "Invalid client credentials"}` | No |
| Client is inactive | 401 | `{"detail": "Client is inactive"}` | No |
| `client_id` or `client_secret` missing | 422 | `{"detail": [...]}` | No |
| Unexpected failure | 500 | Not part of the contract; retry later | No |
