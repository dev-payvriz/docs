title: "List DigiLocker issuer organisations"
sidebarTitle: "DigiLocker: issuers"
description: "Get the list of DigiLocker issuer organisation ids and their names."
openapi: "openapi2.0.json GET /verify/digilocker/org_master"
---

Returns every organisation that issues documents into DigiLocker (`org_id`) with its name (`org_name`), for example universities and boards. The list does not depend on a holder, so no `reference_key` and no request body are needed. The list changes rarely: fetch it once and cache it, because every call is charged. For document type codes, see [List DigiLocker document types](/api-reference/aadhaar/digilocker-doc-master).

## Billing

Charged on every successful call (`status: "success"`). `chargeble` and `user_consent` are `"true"` only on a charged call.

<Warning>
This endpoint has no `Idempotency-Key` support. A retried call runs again and can be charged twice. Retry only after you have confirmed the first call failed.
</Warning>
