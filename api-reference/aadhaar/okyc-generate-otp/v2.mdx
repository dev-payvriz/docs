Step 1 of the Aadhaar Offline KYC (OKYC) flow. Sends an OTP to the mobile number linked to the given Aadhaar number and returns a `session_id` used to complete verification in [Step 2](/api-reference/aadhaar/okyc-get-result/v2).

<Steps>
  <Step title="Generate OTP">
    Call this endpoint with the Aadhaar number. UIDAI sends an OTP to the mobile number linked to that Aadhaar. You receive a `session_id`.
  </Step>
  <Step title="Verify OTP & get result">
    Call [OKYC Verify OTP & Get Result](/api-reference/aadhaar/okyc-get-result/v2) with the `session_id` and the OTP the user received, to retrieve verified identity data.
  </Step>
</Steps>

## Authentication

<ParamField header="X-Client-ID" type="string" required>Your IDTO client ID.</ParamField>
<ParamField header="X-API-KEY" type="string" required>Your IDTO API key.</ParamField>

## Request Body

<ParamField body="aadhaar_number" type="string" required>Aadhaar number (12 digits).</ParamField>
<ParamField body="user_consent" type="boolean" required>Must be `true` — explicit consent to fetch Aadhaar OKYC data.</ParamField>
<ParamField body="user_id" type="string" default="null">Optional caller-supplied end-user identifier.</ParamField>
<ParamField body="workflow_session_token" type="string" default="null">Optional Workflow V2 session token; when present, billing is attributed to the session instead of this call.</ParamField>

## Response Body

<ResponseField name="status" type="string">`"success"` for a 2xx response (both full success and invalid); `"error"` for a raised exception (non-2xx).</ResponseField>
<ResponseField name="message" type="string">Human-readable message. Always present.</ResponseField>
<ResponseField name="error_code" type="string">Nullable. One of the codes in [Error Codes](#error-codes) below.</ResponseField>
<ResponseField name="data" type="object">
  Nullable — session data on success; `null` on non-success.
  <Expandable title="data fields">
    <ResponseField name="session_id" type="string">Session identifier to pass to Step 2 along with the OTP.</ResponseField>
    <ResponseField name="masked_mobile" type="string">Nullable. The masked mobile number the OTP was sent to, e.g. `"XXXXXX7890"`.</ResponseField>
    <ResponseField name="otp_expiry_seconds" type="integer">Nullable. Seconds until the OTP expires.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="tranx_id" type="string">Nullable. Internal transaction identifier.</ResponseField>
<ResponseField name="timestamp" type="string">Nullable.</ResponseField>
<ResponseField name="billed" type="boolean">Whether this call was billed to the customer.</ResponseField>
