Legacy Aadhaar Offline KYC OTP generation endpoint. New integrations should use [OKYC Generate OTP v2](/api-reference/aadhaar/okyc-generate-otp/v2) instead.

## Authentication

<ParamField header="X-Client-ID" type="string" required>Your IDTO client ID.</ParamField>
<ParamField header="X-API-KEY" type="string" required>Your IDTO API key.</ParamField>

## Request Body

<ParamField body="aadhaar_number" type="string" required>12-digit Aadhaar number.</ParamField>

<Info>
  This endpoint also accepts a `uid` field as an alias for `aadhaar_number` on some accounts; new integrations should send `aadhaar_number`.
</Info>

## Response Body

<ResponseField name="status" type="string">`"success"` or `"error"`.</ResponseField>
<ResponseField name="message" type="string">Human-readable message.</ResponseField>
<ResponseField name="error_code" type="string">Nullable.</ResponseField>
<ResponseField name="data" type="object">
  Nullable.
  <Expandable title="data fields">
    <ResponseField name="session_id" type="string">Session identifier to pass to Step 2 along with the OTP.</ResponseField>
    <ResponseField name="masked_mobile" type="string">Nullable.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="tranx_id" type="string">Nullable.</ResponseField>
<ResponseField name="timestamp" type="string">Nullable.</ResponseField>

## Error Codes

| Error Code | HTTP Status | Meaning |
| --- | --- | --- |
| `IDTO_001` | 400 or 422 | The request was invalid or missing a required field. |
| `IDTO_006` | 429 | Too many requests. |
| `IDTO_007` | 500 | Configuration issue. |
| `IDTO_008` | 503 | Service temporarily unavailable. |

See the full [Error Codes reference](/error-codes).

## Code Example

```bash cURL
curl --request POST \
  --url https://prod.idto.ai/verify/okyc_generate_otp \
  --header 'X-Client-ID: your_client_id' \
  --header 'X-API-KEY: your_api_key' \
  --header 'Content-Type: application/json' \
  --data '{
    "aadhaar_number": "999999990019"
  }'
```
