Decodes the secure QR code printed on an Aadhaar card (from an uploaded image or PDF) and returns the identity fields encoded in it, including whether the UIDAI signature could be verified.

<Warning>
  Gate your application logic on `data.authentic`, not on `status` — `status` is `"success"` for every readable QR, including ones whose signature failed verification or couldn't be checked at all.
</Warning>

## Authentication

<ParamField header="X-Client-ID" type="string" required>Your IDTO client ID.</ParamField>
<ParamField header="X-API-KEY" type="string" required>Your IDTO API key.</ParamField>

## Request Body

This endpoint takes `multipart/form-data`, not JSON.

<ParamField body="file" type="file" required>Aadhaar QR image or PDF — clear JPG, PNG, or PDF, with the QR code at least ~468px.</ParamField>
<ParamField body="user_consent" type="boolean" required>Must be `true` — the holder consents to reading their Aadhaar QR. Requests with `false` or a missing value are rejected with `IDTO_005`.</ParamField>
<ParamField body="include_photo" type="boolean" default="false">If `true`, asks for the QR portrait as a base64 PNG in `data.photo`. Best effort — `photo` may still be `null` if the QR carries no portrait or it fails to decode.</ParamField>

## Response Body

<ResponseField name="status" type="string">`"success"` whenever the QR was readable — regardless of signature verification.</ResponseField>
<ResponseField name="message" type="string">Human-readable description of the result.</ResponseField>
<ResponseField name="error_code" type="string">Nullable.</ResponseField>
<ResponseField name="data" type="object">
  Nullable — QR data on success.
  <Expandable title="data fields">
    <ResponseField name="authentic" type="boolean">Nullable. `true` if the UIDAI signature was checked and matched, `false` if checked and mismatched, `null` if no signature check ran.</ResponseField>
    <ResponseField name="is_signed" type="boolean">Whether the QR carries a UIDAI signature at all.</ResponseField>
    <ResponseField name="reference_id" type="string">Nullable.</ResponseField>
    <ResponseField name="name" type="string">Nullable.</ResponseField>
    <ResponseField name="dob" type="string">Nullable.</ResponseField>
    <ResponseField name="gender" type="string">Nullable.</ResponseField>
    <ResponseField name="address" type="string">Nullable. Full address as a single formatted string.</ResponseField>
    <ResponseField name="pincode" type="string">Nullable.</ResponseField>
    <ResponseField name="has_photo" type="boolean">Whether a photo is present in `photo`.</ResponseField>
    <ResponseField name="photo" type="string">Nullable. Base64-encoded portrait.</ResponseField>
    <ResponseField name="photo_mime" type="string">Nullable.</ResponseField>
    <ResponseField name="extras" type="object">Decomposed address components and vendor metadata when available. May be `{}`.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="billed" type="boolean">Whether this call was billed to your account.</ResponseField>

## Error Codes

| Error Code | HTTP Status | Meaning |
| --- | --- | --- |
| `IDTO_001` | 400 or 422 | The request was invalid or missing a required field. |
| `IDTO_005` | 400 | Required consent was not provided in the request. |
| `IDTO_204` | 422 | No readable QR code was found in the submitted image. |
| `IDTO_503` | 413 | The uploaded image could not be processed, or was too large. |

See the full [Error Codes reference](/error-codes).

## Code Example

```bash cURL
curl --request POST \
  --url https://prod.idto.ai/v2/verify/aadhaar_qr \
  --header 'X-Client-ID: your_client_id' \
  --header 'X-API-KEY: your_api_key' \
  --form 'file=@aadhaar_qr.jpg' \
  --form 'user_consent=true'
```
