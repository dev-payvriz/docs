Legacy Aadhaar QR decode endpoint. New integrations should use [Aadhaar QR Decode v2](/api-reference/aadhaar/aadhaar-qr-decode/v2) instead, which also verifies the UIDAI signature.

## Authentication

<ParamField header="X-Client-ID" type="string" required>Your IDTO client ID.</ParamField>
<ParamField header="X-API-KEY" type="string" required>Your IDTO API key.</ParamField>

## Request Body

This endpoint takes `multipart/form-data`, not JSON. Send exactly one of the following two fields.

<ParamField body="file" type="file">Aadhaar QR image file. Send this **or** `image_b64`, not both.</ParamField>
<ParamField body="image_b64" type="string">Base64-encoded image bytes. Send this **or** `file`, not both.</ParamField>

## Response Body

<ResponseField name="status" type="string">`"success"` when the QR was read, `"failed"` when no readable QR was found.</ResponseField>
<ResponseField name="message" type="string">Human-readable description of the result.</ResponseField>
<ResponseField name="data" type="object">
  On success: decoded identity fields.
  <Expandable title="data fields (success)">
    <ResponseField name="name" type="string">Full name.</ResponseField>
    <ResponseField name="dob" type="string">Date of birth, `DD-MM-YYYY`.</ResponseField>
    <ResponseField name="gender" type="string">e.g. `"M"`.</ResponseField>
    <ResponseField name="address" type="string">Full address as a single formatted string.</ResponseField>
    <ResponseField name="id_number" type="string">Reference/ID number encoded in the QR.</ResponseField>
    <ResponseField name="e_signed" type="boolean">Whether the QR carries a UIDAI signature. This endpoint does not verify the signature.</ResponseField>
    <ResponseField name="photo_present" type="boolean">Whether a photo is embedded in the QR.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="error_code" type="string">Nullable.</ResponseField>
<ResponseField name="tranx_id" type="string">Internal transaction identifier.</ResponseField>
<ResponseField name="timestamp" type="string">Creation timestamp.</ResponseField>

<Warning>
  Unlike [v2](/api-reference/aadhaar/aadhaar-qr-decode/v2), this endpoint does not verify the QR's UIDAI signature — `e_signed` only reports whether a signature is _present_, not whether it's _valid_.
</Warning>

## Error Codes

| Error Code | HTTP Status | Meaning |
| --- | --- | --- |
| `IDTO_001` | 400 or 422 | The request was invalid or missing a required field. |
| `IDTO_204` | 422 | No readable QR code was found in the submitted image. |

See the full [Error Codes reference](/error-codes).

## Code Example

```bash cURL
curl --request POST \
  --url https://prod.idto.ai/verify/aadhaar_qr \
  --header 'X-Client-ID: your_client_id' \
  --header 'X-API-KEY: your_api_key' \
  --form 'file=@aadhaar_qr.jpg'
```
