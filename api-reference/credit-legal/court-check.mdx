Search court records for cases against a person, using their name and address, with father's name as an optional filter. Results are ranked by a weighted match score: records above 85 percent are returned in `strong_match`, the rest in `possible_match`, and records ruled out in `eliminated_data`. `totalResult` is the number of records found.

A search that finds nothing is a completed search: `status` is `success`, every list is empty and the call is charged. Review `possible_match` records manually before you act on them.

<Warning>
This endpoint has no idempotency support. A retried request runs the verification again and can be charged again. Retry only after you have confirmed the first call did not return a response.
</Warning>

## Billing

Charged only when the response `status` is `success`. A charged call carries `"chargeble": "true"` and `"user_consent": "true"`; an uncharged call has neither field.

## Response fields

| Field | Type | Description |
|---|---|---|
| `status` | string | `success` when the search completed. |
| `result.eliminated_data` | array | Records considered and ruled out. |
| `result.possible_match` | array | Case records with a weighted match of 85 percent or less. Review manually. |
| `result.strong_match` | array | Case records with a weighted match above 85 percent. |
| `result.totalResult` | number | Number of records found. |
| `tranx_id` | string | IDTO transaction id for this call. |
| `timestamp` | string | Time IDTO recorded the call, ISO 8601. |
| `chargeble` | string | `"true"` on a charged call, absent otherwise. |
| `user_consent` | string | `"true"` on a charged call, absent otherwise. |

## Errors

| Code | HTTP | When | Billed |
|---|---|---|---|
| `null` | 400 | *Wrapped.* Credits are insufficient, or the product is not enabled for your account. | No |
| No code | 401 | Missing or invalid `X-Client-ID` or `X-API-Key`. | No |
| No code | 403 | The client is inactive or not allowed to call this endpoint. | No |
| No code | 422 | Body failed schema validation. Body: `{"detail": [{"loc": [...], "msg": "..."}]}`. | No |
| No code | 500 | Unexpected failure. The body is not part of the contract; retry later. | No |

`Code` is the `error_code` in the body. Errors marked *wrapped* return `{"detail": {"status": "error", "message": "...", "error_code": null, "data": null, "tranx_id": "...", "timestamp": "..."}}`.

## Test scenarios

Use these input classes in staging to exercise each outcome.

| Input | Expected result | Billed |
|---|---|---|
| Name and address of a person with no cases | 200, empty lists, `totalResult: 0` | Yes |
| Name and address that match recorded cases | 200, records in `strong_match` or `possible_match` | Yes |
| `name` or `address` missing from the body | 422 | No |
