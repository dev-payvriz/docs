## Errors

| Code | HTTP | Message | Billed |
| --- | --- | --- | --- |
| `IDTO_201` | 200 | Bank account is invalid. | Yes |
| `IDTO_401` | 400 | Invalid IFSC code. | No |
| `IDTO_402` | 400 | Invalid account number. | No |
| `IDTO_403` | 400 | Invalid reference_id. | No |
| `IDTO_001` | 400 | Invalid input. Please check the request and try again. | No |
| `IDTO_005` | 400 | User consent is required to proceed. | No |
| `IDTO_006` | 429 | Too many requests. Please wait a moment and retry. | No |
| `IDTO_007` | 500 | Verification could not be completed due to a service configuration issue. | No |
| `IDTO_008` | 503 | The verification service is momentarily busy. Please retry shortly. | No |
| `IDTO_009` | 402 | Insufficient credits or balance. Please recharge and try again. | No |
| `IDTO_010` | 422 | Idempotency-Key was already used with a different request body. | No |
| `IDTO_101` | 400 | A required parameter is missing from the request. | No |
| `IDTO_102` | 400 | A required parameter is missing from the request. | No |
| `IDTO_103` | 503 | This verification could not be completed. Please retry shortly. | No |
