Authenticate with your account email and password to receive a short-lived bearer access token. Use this token in the `Authorization: Bearer <access_token>` header for the [Balance](/api-reference/account/balance) endpoint and any other account-management endpoint. Verification endpoints (PAN, Aadhaar, etc.) use your `X-Client-ID`/`X-API-KEY` headers instead — not this token.

## Request Body

<ParamField body="email" type="string" required>
  Your IDTO account email address.
</ParamField>

<ParamField body="password" type="string" required>
  Your IDTO account password.
</ParamField>

## Response Body

<ResponseField name="access_token" type="string">
  Bearer token to send as `Authorization: Bearer <access_token>` on subsequent authenticated requests.
</ResponseField>

<ResponseField name="token_type" type="string">
  Always `"bearer"`.
</ResponseField>

<ResponseField name="expires_in" type="integer">
  Seconds until `access_token` expires.
</ResponseField>

## Code Example

```bash cURL
curl --request POST \
  --url https://prod.idto.ai/auth/login \
  --header 'Content-Type: application/json' \
  --data '{
    "email": "you@example.com",
    "password": "your_password"
  }'
```
