Validate a PAN together with the holder's name and date of birth directly against the NSDL (Protean) source of record. Unlike [PAN Verification](/api-reference/pan/pan-verification/v2), this endpoint requires and cross-checks `name` and `dob`.

## Authentication

<ParamField header="X-Client-ID" type="string" required>Your IDTO client ID.</ParamField>
<ParamField header="X-API-KEY" type="string" required>Your IDTO API key.</ParamField>

## Request Body

<ParamField body="pan_number" type="string" required>PAN number (10 characters: 5 letters, 4 digits, 1 letter).</ParamField>
<ParamField body="name" type="string" required>Name as provided by the user, matched against the NSDL record.</ParamField>
<ParamField body="dob" type="string" required>Date of birth, e.g. `"1990-05-21"`.</ParamField>
<ParamField body="user_id" type="string" default="null">Optional identifier of your own choosing for correlating this call with your records.</ParamField>

## Response Body

<ResponseField name="status" type="string">`"success"` or `"error"`.</ResponseField>
<ResponseField name="message" type="string">Human-readable message.</ResponseField>
<ResponseField name="error_code" type="string">Nullable.</ResponseField>
<ResponseField name="data" type="object">
  Nullable.
  <Expandable title="data fields">
    <ResponseField name="pan_number" type="string">Nullable.</ResponseField>
    <ResponseField name="name_match" type="boolean">Nullable. Whether the supplied name matched the NSDL record.</ResponseField>
    <ResponseField name="dob_match" type="boolean">Nullable. Whether the supplied date of birth matched the NSDL record.</ResponseField>
    <ResponseField name="pan_status" type="string">Nullable.</ResponseField>
    <ResponseField name="aadhaar_seeding_status" type="string">Nullable. e.g. `"LINKED"`, `"NOT LINKED"`.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="tranx_id" type="string">Nullable.</ResponseField>
<ResponseField name="timestamp" type="string">Nullable.</ResponseField>

## Code Example

```bash cURL
curl --request POST \
  --url https://prod.idto.ai/verify/pan_nsdl \
  --header 'X-Client-ID: your_client_id' \
  --header 'X-API-KEY: your_api_key' \
  --header 'Content-Type: application/json' \
  --data '{
    "pan_number": "ABCDE1234F",
    "name": "Rahul Sharma",
    "dob": "1990-05-21"
  }'
```
