Verify a PAN issued to a business, company, or firm entity (rather than an individual) and retrieve organisation details.

## Authentication

<ParamField header="X-Client-ID" type="string" required>Your IDTO client ID.</ParamField>
<ParamField header="X-API-KEY" type="string" required>Your IDTO API key.</ParamField>

## Request Body

<ParamField body="pan_number" type="string" required>PAN number (5 letters, 4 digits, 1 letter).</ParamField>
<ParamField body="user_id" type="string" default="null">Optional identifier of your own choosing for correlating this call with your records.</ParamField>

## Response Body

<ResponseField name="status" type="string">`"success"` or `"error"`.</ResponseField>
<ResponseField name="message" type="string">Human-readable message.</ResponseField>
<ResponseField name="error_code" type="string">Nullable.</ResponseField>
<ResponseField name="data" type="object">
  Nullable.
  <Expandable title="data fields">
    <ResponseField name="pan_number" type="string">Nullable.</ResponseField>
    <ResponseField name="company_name" type="string">Nullable. Registered organisation name.</ResponseField>
    <ResponseField name="pan_status" type="string">Nullable.</ResponseField>
    <ResponseField name="category" type="string">Nullable. e.g. `"Company"`, `"Firm"`, `"Trust"`.</ResponseField>
    <ResponseField name="cin" type="string">Nullable. Corporate Identification Number, when linked.</ResponseField>
    <ResponseField name="incorporation_date" type="string">Nullable.</ResponseField>
    <ResponseField name="directors" type="string[]">Nullable. Director names, when available from the vendor.</ResponseField>
    <ResponseField name="email" type="string">Nullable. Masked registered email.</ResponseField>
    <ResponseField name="mobile" type="string">Nullable. Masked registered mobile.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="tranx_id" type="string">Nullable.</ResponseField>
<ResponseField name="timestamp" type="string">Nullable.</ResponseField>

```bash cURL

  --url https://prod.idto.ai/verify/business_pan \
  --header 'X-Client-ID: your_client_id' \
  --header 'X-API-KEY: your_api_key' \
  --header 'Content-Type: application/json' \
  --data '{
    "pan_number": "AAACS1234F"
  }'
```
