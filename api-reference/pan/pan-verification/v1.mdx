Legacy PAN verification endpoint. New integrations should use [PAN Verification v2](/api-reference/pan/pan-verification/v2) instead.

## Authentication

<ParamField header="X-Client-ID" type="string" required>
  Your IDTO client ID.
</ParamField>

<ParamField header="X-API-KEY" type="string" required>
  Your IDTO API key.
</ParamField>

## Request Body

<ParamField body="pan_number" type="string" required>
  PAN number (10 characters: 5 letters, 4 digits, 1 letter).
</ParamField>

<ParamField body="name" type="string" required>
  Name as provided by the user, for optional name-matching against the PAN record.
</ParamField>

<ParamField body="dob" type="string" required>
  Date of birth, e.g. `"1990-05-21"`.
</ParamField>

<ParamField body="user_id" type="string" default="null">
  Optional identifier of your own choosing for correlating this call with your records. Not echoed in the response.
</ParamField>

## Response Body

<ResponseField name="status" type="string">
  `"success"` or `"error"`.
</ResponseField>
<ResponseField name="message" type="string">
  Human-readable message.
</ResponseField>
<ResponseField name="error_code" type="string">
  Nullable. Present when applicable.
</ResponseField>
<ResponseField name="data" type="object">
  Nullable. PAN data on success.

  <Expandable title="data fields">
    <ResponseField name="pan_name" type="string">Nullable.</ResponseField>
    <ResponseField name="pan_number" type="string">Nullable.</ResponseField>
    <ResponseField name="pan_status" type="string">Nullable.</ResponseField>
    <ResponseField name="category" type="string">Nullable.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="tranx_id" type="string">Nullable. Internal transaction identifier.</ResponseField>
<ResponseField name="timestamp" type="string">Nullable.</ResponseField>

## Error Codes

| Error Code | HTTP Status | Meaning |
| --- | --- | --- |
| `IDTO_001` | 400 or 422 | The request was invalid or missing a required field. |
| `IDTO_006` | 429 | Too many requests. |
| `IDTO_007` | 500 | Configuration issue. |
| `IDTO_008` | 503 | Service temporarily unavailable. |

See the full [Error Codes reference](/error-codes).

## Code Example

```bash cURL
curl --request POST \
  --url https://prod.idto.ai/verify/pan_verification \
  --header 'X-Client-ID: your_client_id' \
  --header 'X-API-KEY: your_api_key' \
  --header 'Content-Type: application/json' \
  --data '{
    "pan_number": "ABCDE1234F",
    "name": "Rahul Sharma",
    "dob": "1990-05-21"
  }'
```
