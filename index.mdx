Welcome to the IDTO Verification API — a unified REST platform for verifying Indian government-issued identities, corporate records, financial data, and biometric documents. Whether you need instant PAN validation, Aadhaar-based KYC, GST lookups, or face-match verification, every service is available through a consistent, secure API with predictable response envelopes and clear error codes.
