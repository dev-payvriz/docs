IDTO is a comprehensive REST API platform that gives you a single integration point for every identity, document, and business verification workflow used in India. From instant PAN validation and Aadhaar OTP-based KYC to GST lookups, face-match biometrics, and DigiLocker document retrieval, IDTO abstracts the complexity of dealing with multiple government data sources behind a consistent, well-documented interface — so your engineering team can ship compliant verification flows in days, not months.

## Base URL

All API requests are made over HTTPS to the production server:

```
https://prod.idto.ai
```

There are no separate staging or sandbox hostnames. Use test credentials provided by the IDTO team during development to avoid consuming production credits.

## API Versioning

IDTO exposes two API versions that co-exist on the same host:

| Version | Path prefix | Status | Notes |
|---------|-------------|--------|-------|
| v1 | `/verify/...` | Legacy | Supported, but no new features added |
| v2 | `/v2/verify/...` | **Recommended** | Flat response envelope, richer error codes, idempotency support |

Use **v2 for all new integrations**. The v2 response envelope looks like this:

```json
{
  "status": "success",
  "message": "PAN details fetched successfully",
  "error_code": null,
  "data": { ... },
  "billed": true,
  "tranx_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "timestamp": "2026-07-11T10:20:30.123456"
}
```

The v1 envelope wraps errors differently (inside a `detail` object), which makes consistent error handling harder. Migrate existing v1 integrations to v2 when possible.
