This guide walks you through making your first live API call against the IDTO Verification API. By the end you'll have verified a PAN number, inspected the structured response, and know exactly how to branch on success, no-match, and error outcomes — all in under five minutes.

<Steps>

### Get Your API Credentials

Every request to a verification endpoint requires two headers: your **Client ID** and your **API Key**. These are issued when you create an IDTO account.

Contact [tech@idto.ai](mailto:tech@idto.ai) to request access. Once provisioned, you will receive:

- `X-Client-ID` — your unique client identifier
- `X-API-KEY` — your secret API key

Store both values in environment variables rather than hard-coding them. The examples below assume the following shell environment:

```bash
export IDTO_CLIENT_ID="your_client_id_here"
export IDTO_API_KEY="your_api_key_here"
```

<Tip>
  Never commit API credentials to source control. Use a secrets manager or a `.env` file that is listed in `.gitignore`.
</Tip>

### Make Your First PAN Verification Call

The PAN Validation endpoint (`POST /v2/verify/pan_validation`) is the simplest place to start. Send a valid 10-character PAN and set `user_consent` to `true` — consent is required for all verification services.

<CodeGroup>

```bash curl
curl --request POST \
  --url https://prod.idto.ai/v2/verify/pan_validation \
  --header "X-Client-ID: $IDTO_CLIENT_ID" \
  --header "X-API-KEY: $IDTO_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "pan_number": "ABCDE1234F",
    "user_consent": true
  }'
```

```python Python
import os
import requests

url = "https://prod.idto.ai/v2/verify/pan_validation"

headers = {
    "X-Client-ID": os.environ["IDTO_CLIENT_ID"],
    "X-API-KEY": os.environ["IDTO_API_KEY"],
    "Content-Type": "application/json",
}

payload = {
    "pan_number": "ABCDE1234F",
    "user_consent": True,
}

response = requests.post(url, json=payload, headers=headers)
response.raise_for_status()
print(response.json())
```

```javascript Node.js
import fetch from "node-fetch"; // or use the built-in fetch in Node 18+

const url = "https://prod.idto.ai/v2/verify/pan_validation";

const response = await fetch(url, {
  method: "POST",
  headers: {
    "X-Client-ID": process.env.IDTO_CLIENT_ID,
    "X-API-KEY": process.env.IDTO_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    pan_number: "ABCDE1234F",
    user_consent: true,
  }),
});

const data = await response.json();
console.log(data);
```

</CodeGroup>

### Understand the Response

A successful verification returns HTTP `200` with a v2 envelope. The `data` object contains the extracted PAN details, `billed: true` indicates that a credit was consumed, and `tranx_id` is a unique UUID you can use for support queries.

```json
{
  "status": "success",
  "message": "PAN details fetched successfully",
  "error_code": null,
  "data": {
    "pan_number": "ABCDE1234F",
    "pan_name": "Rahul Kumar",
    "pan_status": "VALID",
    "aadhaar_linked": true,
    "pan_type": "Individual"
  },
  "billed": true,
  "tranx_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "timestamp": "2026-07-11T10:20:30.123456"
}
```

Key fields to note:

| Field | Type | Description |
|-------|------|-------------|
| `status` | string | `"success"` or `"error"` |
| `error_code` | string \| null | `null` on success; an `IDTO_XXX` code on failure |
| `data.pan_name` | string | Full name of the PAN holder as registered with the Income Tax Department |
| `billed` | boolean | `true` if a credit was deducted for this call |
| `tranx_id` | string | UUID for this transaction — quote this in support tickets |

### Handle Errors

Always branch on the `error_code` field, not on the HTTP status code or the `message` text — message text can change between releases. A `null` `error_code` means the call succeeded.

```python
import os
import requests

response = requests.post(
    "https://prod.idto.ai/v2/verify/pan_validation",
    json={"pan_number": "ABCDE1234F", "user_consent": True},
    headers={
        "X-Client-ID": os.environ["IDTO_CLIENT_ID"],
        "X-API-KEY": os.environ["IDTO_API_KEY"],
    },
)

body = response.json()
error_code = body.get("error_code")

if error_code is None:
    # Verification succeeded
    print("PAN holder:", body["data"]["pan_name"])
elif error_code == "IDTO_202":
    # No record found — this call was still billed
    print("No matching record found for this PAN.")
elif error_code == "IDTO_009":
    # Out of credits — top up the account
    print("Insufficient credits. Please top up your IDTO account.")
elif error_code == "IDTO_005":
    print("User consent was not provided. Set user_consent: true.")
else:
    print(f"Verification failed with error code: {error_code}")
```
